## Goal
Two small CNNs (CNN2, CNN3) train end-to-end on the 54k train split with early stopping, their training curves are
drawn, and the final CNN is chosen on validation. No code in this phase touches the test set.

## Previous phase summary
v1 is complete (tag `v1.0.0`): 12 classical experiments; best by validation `rbf_svm_hog` (val 0.9157, test 0.9108);
Shirt has the lowest recall for every model. `load_splits()` returns the fixed 54k / 6k / 10k split as float32 images
in [0, 1], shape (N, 28, 28). `evaluate()` scores any object with `.predict()`. See `docs/phases/v1/phase-05-results-analysis.md`.

## In scope — exact features
1. **PyTorch setup**: `torch==2.15.0` in `requirements.txt`; CNN constants and paths in `config.py`; `set_seed()` seeds PyTorch; `models/` gitignored.
   - Acceptance: `python -c "import torch; print(torch.__version__)"` prints `2.15.0`; Phase 1 notebooks still import.
2. **Data loaders** (F-15): `make_loaders()`.
   - Acceptance: one train batch has shape (64, 1, 28, 28); the dict has only `train` and `val`.
3. **CNN2, CNN3, `count_params`, `CNNPredictor`** (F-16).
   - Acceptance: `count_params(CNN2()) == 421642`, `count_params(CNN3()) == 241546`; `CNNPredictor(CNN2()).predict(X_val[:5])` returns 5 ints.
4. **`train_cnn()`** (F-17): Adam + cross-entropy, early stopping on val loss (patience 5), best weights restored, history CSV, val JSON, checkpoint.
   - Acceptance: files match `data-formats.md` §13–15; a second run gives the same `best_val_acc`.
5. **Notebook 06, training part** (F-18): shape walk-through of one batch through CNN2, parameter counts, train CNN2 and CNN3, training curves, choice on val.
   - Acceptance: `cnn_training_curves.png` saved; the final CNN and both val accuracies are written in the notebook and in a decision entry.
